# Brown Design Empire

Fashion site for **Brown Design Empire** by Ise Brawn — a Nuxt 3 / Vue 3 runway shop styled with Tailwind CSS.

## Stack

- Vue.js / Nuxt.js
- Tailwind CSS
- Local cart, wishlist, and order request (saved in the browser)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Build for production |
| `npm run generate` | Generate a static site |
| `npm run preview` | Preview the production build |

## Pages

- `/` — Atelier 2026 runway
- `/clothing` — Shop edit
- `/product/[id]` — Piece detail
- `/lookbook` — Look gallery
- `/collections` — His & Hers, wedding, suits, evening
- `/house` — Brand story and contact note
